# J-Mail Master

日本語ビジネスメール生成・推敲アプリケーション。
要件に基づいて、AI（ルールベースまたはOpenAI API）を利用してプロフェッショナルなビジネスメールを生成します。

## 開発環境について

現在、バックエンド側の実装およびフロントエンドのコンポーネント実装がすべて完了しています。

### バックエンド (FastAPI)

1. `backend/` フォルダへ移動します。
2. Python環境にて必要なパッケージをインストールします。
   ```bash
   pip install -r requirements.txt
   ```
3. `.env` ファイルに `OPENAI_API_KEY` を設定してください（設定しない場合はモックモードで動作します）。
4. FastAPI サーバーを起動します。
   ```bash
   uvicorn main:app --reload --port 8000
   ```

### フロントエンド (React + Vite)

本環境では `Node.js` および `npm` が見つからなかったため、パッケージのインストールおよびビルドが未完了です。ご自身のローカル環境にNode.jsをインストールしていただき、以下の手順で起動してください。

1. `frontend/` フォルダへ移動します。
2. 依存関係をインストールします。
   ```bash
   npm install
   ```
3. 開発サーバーを起動します。
   ```bash
   npm run dev
   ```

## 機能概要

- **メール生成**: 相手の属性（目上、同僚など）や用途（謝罪、依頼など）を指定してメール文面を生成
- **トーン調整**: 「丁寧」「簡潔」の2パターンのバリアントを一度に提案
- **多言語対応**: 日本語、英語、韓国語でのUI表示切替
- **プロファイル機能**: ユーザーの会社名や署名を保存し、生成メールに自動適用
- **推敲チップ**: 「もう少し柔らかく」「もっと簡潔に」などの1クリック推敲機能
